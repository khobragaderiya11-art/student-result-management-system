🎓 Student Result Management System | Python Tkinter + Excel

This video demonstrates my Student Result Management System mini project developed using Python, Tkinter, OpenPyXL and Excel.

📌 Project Features:

• Add student details and subject marks
• Automatic calculation of Total Marks
• Automatic Percentage calculation
• Pass/Fail result calculation
• Search student result using Roll Number
• Display all student results using Tkinter Treeview
• Store student records automatically in Excel

🛠️ Technologies Used:

• Python
• Tkinter
• OpenPyXL
• Microsoft Excel

📂 Excel File:

The project automatically creates student_results.xlsx to store student records.
